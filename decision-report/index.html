Section 02 · Architecture & Engines

技术范式与四代 Code2Video 渲染引擎

纯像素视频模型的三大物理硬边界

  • 非局部可控性：改第 4 秒文案或产品颜色往往触发整段重新采样，无法独立改单层图层。
  • 精确符号幻觉：UI 界面、财务数字、长串中文与公式在潜空间采样中极易扭曲错字。
  • 单次时长与拼接税：主流单段上限为 4–30s（Veo 3.1 4–8s、Omni 1.2 Flash 15s、Kling 4.0 / Wan 3.0 / Seedance 2.5 30s），长片跨段拼接易生人物色调断层。

混合双引擎的两种落地形态（2026 收敛方向）

  • 工业编排（Code-as-Orchestrator）：代码统筹节拍时间轴、字幕与数据卡片，视频模型仅作写实镜头供片方（代表：OpenMontage、Always Allow、Anfloy）。
  • 物理白模预演（Code-as-Previs）：微软 CVM、VideoCoCo 与 Video-Coder 先用 Three.js/Blender 灰模锁死碰撞、计数与相机轨迹，再注入扩散模型早期采样；但灰模不带表面反光信息，Material 维度仍弱于纯像素模型。

7 类商业场景选型决策矩阵

业务场景 推荐路线 推荐技术栈组合 经济与工程决胜点
1. SaaS 产品发布片 & PR 变更日志 纯 Code2Video HyperFrames / OpenFilm + Playwright + GPT-6.1 Sol / Opus 5.5 UI 与代码零失真；脚本进 Git 与 CI/CD 联动，迭代只改增量。
2. 千人千面年度回顾 / 财报简报 纯 C2V（模板化） Remotion Lambda（React 团队）或 HyperFrames --batch 建好模板后批产 10,000 条仅付 ~$200 云算力，LLM 边际 Token 归零。
3. 数学 / 算法 / 物理硬核科普 纯 C2V（专用引擎） ManimGX / Code2Video + Whisper 字级对齐 + 本地 TTS 公式几何严格精确；ManimGX 将单次渲染压至 3 秒级，全片 <¥5。
4. 品牌情绪片、自然风光、写实人物 纯视频生成模型 Omni 1.2 Flash（对话改图）/ Kling 4.0（30s）/ Veo 3.1 皮肤光影是代码天花板；用 480p Draft / Lite 抽卡 + 精选 1080p 降本 40%–77%。
5. 电商广告百变体矩阵 / 带货短剧 混合双引擎 Seedance 2.5 / Kling 4.0（锁商品）+ HyperFrames（叠价格/画幅） 多参考把商用过稿率提至 58%；价格与免责声明严禁扩散生成，由代码压印。
6. 物理精准的复杂 3D 广告 / 仿真 混合 (Code-as-Previs) Three.js / Blender 白模预演 + CVM / Video-Coder / Seedance 代码先算准物体计数与碰撞轨迹，再让视频模型补全光影材质。
7. 口播 / 访谈 / 录屏粗剪与切片 Agentic EDL 剪辑 video-use + ElevenLabs Scribe / Whisper + FFmpeg 不重绘原片像素，用 12KB 带时间戳文本决策切点，避开 4,500 万看图 Token。
Section 05 · Engineering Playbook

C2V 与混合管线五大工程降本法则（省 50%–80%）

模型牌价只是起点，决定最终账单上限的是路由策略、修复粒度与音画对齐顺序。

1. 模型分层路由（Orchestrator + Worker），告别全链路用 Opus / Fable 用 Opus 5.5 或 Fable 5.2 生成顶层视觉规范（DESIGN.md）与核心镜头原型；将组件填槽与样式微调下放给 GPT-6.1 Sol（$0.31/任务，1369 Elo） 或 Haiku 5.5（$0.08），削减 80%–90% 推理费用。
2. 局部自修复（ScopeRefine）优先于盲目并行 Code2Video 消融实验显示，去掉并行仅影响墙钟时间（×5.6），而去掉局部修复改用全量重抽会同时让时间 ×2.8、Token ×1.6。
3. 上下文阈值截断（150K Token 防雪崩法则） 单会话接近 150K tokens 时立即执行 /clear 并通过 HANDOFF.md 摘要交接，以 ~5K tokens 重启新会话，避免历史 HTML 反复重传引发平方级账单。
4. 启用专用视频 Harness 并严守确定性三禁令 HeyGen 实测专用视频 Harness（拼图抽帧 Contact Sheet + 响度检测 + 安全区检查）可减少 ~35% 交互轮次与 ~30% 成本；代码严禁读系统时间、无种子随机与渲染期联网。
5. 先“量”音轨再“算”时间轴，提前隔离许可与色域暗坑 先出 TTS 并用 Whisper/wav2vec2 对齐字级时间戳驱动动画（防按字数估算到第 15 句漂移 5 秒）；≥4 人公司留意 Remotion 全员门禁；混剪统一转码 yuv420p 并 await document.fonts.ready。
