列判定口径：

- **来源与预览**：身份、原始来源可确认；有真实官方预览，不使用假效果。
- **内容**：项目要有四问分析与限制；网页案例要有不少于 48 字的说明与至少 1 条技术要点；精读要有 5 行以上链路拆解、正文分析与来源/证据缺口。
- **外部入口**：至少一个有效链接，有哪个显示哪个、不显示空按钮。
- **字段与资产**：`npm run check` 全量通过；slug 唯一、行业与技术栈在词表内、资产存在且非空、首条媒体登记与封面/缩略图一致、相关条目存在。
- **代码许可**：单独登记 SPDX / 来源 / 覆盖范围，并明确不覆盖预览媒体；案例合集无 LICENSE 时如实登记「未取得独立 LICENSE 文件」。
- **媒体使用依据**：逐条独立登记权利方、来源 URL、署名与权限备注；脚本拒绝「由代码许可推导」式表述。精读的原帖视频抽帧还会注明「原封面帧为空画面，本站重抽」。**动态预览单独占一条记录**，写明「原视频片段（5 秒静音循环）」；没有动态素材的条目不强行补动效。
- **无实测措辞**：项目写「未运行代码、未复现样片」；案例写「未逐页运行交互」，都不写本站实测结论。
