**权威数据源**是四个内容目录里的 `code_license` / `license` 与 `media_records` 字段（`src/content/projects/*.md`、`src/content/cases/*.md`、`src/content/works/*.md`、`src/content/studies/*.md`），详情页的「媒体与许可登记」表格由它自动渲染；本文件只是便于人工核对的汇总索引。

## 四、动态预览（57 段，57 个媒体文件）

- **来源**：29 个创作案例、23 篇精读取自作者 X 原帖视频；5 个项目取官方 README / Release 的动图或影片（HyperFrames、Lemo、Math-To-Manim、SenseNova、paper-to-animation）。
- **处理方式**：统一截取 5 秒、去除音轨、缩放到 640 宽、H.264 CRF 31、`faststart`，合计 8.9 MB；只做时长与尺寸裁剪，不改画面内容。
- **未收录动效的条目**：`fermat-lean-proof` 与 `os-from-scratch` 的原帖视频与案例主题对不上（同一串帖里的共用片头），按「不硬凑」原则保持静帧；`video-shotcraft` 的官方动图帧间无变化，等同静帧，也未启用。
- **登记**：每段预览在 `media_records` 中有独立条目，注明「原视频片段（5 秒静音循环）」、来源 URL、权利方与使用依据，不由封面或代码许可推导。
- **播放策略**：详情页自动播放、静音、循环；卡片只在桌面悬停时播放，手机不自动加载。

## 六、合计与复核

- 本地媒体共 **231 个文件**：项目 19 + 网页案例 100 + 创作案例 31 + 精读 24 + 动态预览 57，分别位于 `public/media/<slug>/`、`public/media/cases/<slug>/thumb.jpg`、`public/media/works/<slug>/cover.jpg` 与 `public/media/studies/<slug>/cover.jpg`。
- `npm run check` 校验每条媒体依据独立填写，并拒绝「按仓库许可」「由代码许可自动决定」这类推导式表述；同时校验首条媒体记录与封面 / 缩略图一致。
- 卡片默认只显示静态封面；`preview_motion` 全部为空，未启用悬停播放，也没有制作替代动效。
- 页面不把官方素材写成「本站复现」或「实测效果」：项目写「未运行代码、未复现样片」，案例写「未逐页运行交互」。
- 媒体加载失败时回退到说明文字并引导访问原始来源，不使用假效果。
- 第三方外链探测写入 `reports/外链人工复核.md`，区分「确认异常」与「本环境无法判定，待人工确认」，两者都不阻断发布。
- **公开对外托管前**，逐条确认 231 个素材（含 57 段动态预览）的再分发与商用范围；确认结果追加到对应条目的 `permission_note`，不修改许可栏。
