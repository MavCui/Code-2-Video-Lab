# 案例合集接入说明

## 来源

- 合集页：https://miaai-lab.github.io/Claude-Opus-5.5-100-HTML-Files/
- 仓库：https://github.com/miaai-lab/Claude-Opus-5.5-100-HTML-Files
- 内容：100 个自包含单文件 HTML 网页，由 Claude Opus 5.5 生成；每个页面内联全部 CSS / JS、无外部请求，并附带首屏截图与原始提示词。
- 合集仓库有 README，但**没有 LICENSE 文件**。

## 本地化口径

- **中文标题**：保留原名并译为「中文名 — 副题」，英文原名继续显示在详情页副标题，不做重新命名。
- **一句话**：根据官方卡片描述提炼，只写页面确实呈现的内容，不添加未经验证的能力。
- **案例说明**：约 50–90 字，描述画面构成与交互方式；不逐字翻译原文 1000 字符级的长描述。
- **技术要点**：从官方描述与提示词中提取 2 条实现要点，不把「用了某库」写进去（合集本身无外部依赖）。
- **虚构信息**：页面中的品牌、人物与数据由作者标注为虚构，中文本地化照实保留这一说明。

## 分类规则（本次调整）

- **一级分类改为行业**，一个条目单选：品牌与营销、艺术与实验、游戏与互动、数据与工具、教育与科普、媒体与出版、生活与消费、空间与建筑、研究与模型。
- **技术栈独立成标签维度**，可多选，来自页面实际实现：Canvas 2D、SVG、CSS 3D、WebGL、Web Audio、DOM / CSS、原生 JS。
- 原有「教育讲解 / 品牌动效 / 产品演示 / 数据叙事 / 空间与运动 / 论文与文档」不再作为一级分类；12 个项目已同步迁移到行业分类，技术栈仍保留在标签里。
- 展厅同时提供行业单选与技术栈单选两个筛选维度，搜索覆盖名称、介绍、行业与技术栈。

## 媒体与许可

- 100 张首屏截图来自官方 `thumbs/`，压缩至 900×563、JPEG q84，合计约 7 MB。
- 每个案例的 `media_records` 独立登记：来源 URL、来源页、权利方、署名、使用依据、权限备注。
- **代码许可栏登记「未取得独立 LICENSE 文件」**，并注明不推断任何媒体使用权限；不因为合集公开可访问就视为可再分发。
- 截图只作介绍性引用、署名并回链；公开托管或商用前需向权利方单独确认。

## 校验规则

每个 published 案例必须通过：内部字段齐全、行业在词表内、至少一个技术栈标签且在词表内、缩略图存在且非空、三个来源 URL 合法、至少一条媒体登记且首条与缩略图一致、代码许可三项齐全、案例说明不少于 48 字、技术要点不少于 1 条、3 个相关案例均存在且不指向自身。

`npm run check` 对 100 个案例全量执行；当前阻断 0。
