# 案例精读（24 篇）来源与口径

## 一、这批条目是什么

《C2V_案例精读_24例_证据版》是一份工作区文档，从 1,671 条 X 索引与三份合集里挑出 **24 个「能算账」的案例**：每一篇都能回答「这条片花了多久、多少钱、消耗多少额度或 token、用什么链路做出来的」。本站把它作为第四种条目接入展厅，角标为「精读」，与「作品」「案例」「项目」并列。

它与「创作作品」的区别不是题材，而是问题：

- 作品回答「这条片子长什么样、作者怎么做的」。
- 精读回答「这条片子值不值、贵在哪、结论能不能外推」，并且把**口径**和**证据缺口**一起写进去。

## 二、收录原则

1. **必须有可核对的数字或明确的结构描述**。24 篇里 7 篇带完整成本对照表，其余带时长、token、调用次数、镜头数或额度占比中的至少一项。
2. **必须能回到原始 Demo**。每篇顶部都有作者 X 原帖链接，并在页面上标注 Demo 类型（同题对照 / 单条成片 / 过程记录 / 可编辑交付等）。
3. **不做跨案例排名**。不同任务复杂度、成片时长与计价口径不同，本站只复述作者给的数字，不换算、不相除、不排名。
4. **证据缺口照实写**。作者没说的（是否含重试、起止点、输入输出如何计价）统一写「未说明」，不用推测补齐。
5. **负面与反例同样收录**。第 12 篇就是一组被广泛传播、但不能直接相除的数字；第 23 篇是一条没有具体数字的进度抱怨。它们能防止把「个案」读成「基准」。

## 三、24 篇的分布

| 章节 | 篇数 | 说明 |
|---|---|---|
| 10–11 月的链路样本 | 12 | 纯代码、混合、剪辑、工具、平台、中文全流程各取代表 |
| 三份合集里的代表作 | 10 | 同题对照、可编辑交付、片长极限、MCP 跨工具链 |
| 合集之外的扫描补充 | 2 | 负样本与可编辑动效 |

行业分布：艺术与实验 11、数据与工具 4、媒体与出版 3、教育与科普 3、品牌与营销 2、空间与建筑 1。

技术栈标签：Three.js、Blender、Remotion、HyperFrames、After Effects、MCP、Suno、Manim、Canvas 2D、WebGL、Web Audio、FFmpeg、HTML、原生 JS，以及「视频模型」「多智能体」「代码渲染」三个链路级标签和 Claude Opus 5.5 / Fable 5.5 / Fable 5.2。

## 四、页面结构与字段

| 模块 | 字段 | 作用 |
|---|---|---|
| 一句话结论 | `one_liner` | 这篇最值得带走的一句判断，不是剧情简介 |
| 看哪里 | `hint` | 告诉读者对比图里该看哪两处 |
| 链路拆解 | `meta` | 核心定位、适用场景、必备输入、标准流程、AI 职责、关键指标 |
| 为什么值得看 | `body` | 2–3 段分析，解释反直觉之处与可迁移动作 |
| 效果对照与成本 | `cost_table` / `cost_note` | 原样保留作者口径的对照表，附口径说明 |
| 可复用点与适用边界 | `take` | 可以迁移的 / 成立的条件 / 不能外推的 |
| 来源与证据缺口 | `sources` | 原帖、提示词、发布时间与互动快照、缺口、记录版本 |
| 媒体与许可登记 | `license` / `media_records` | 作品许可与预览媒体使用依据分栏，互不推导 |

## 五、动态预览

24 篇中有 **23 篇**配了 5 秒静音循环的原片片段（`preview_motion`），详情页自动播放；第 12 篇原帖已 404，只能保留静帧与对照图。7 篇的对照图是上下两栏或竖版，详情页在视频下方额外保留这张对照图，因为图上烧录的成本与耗时是证据本体，不能被视频替代。

## 六、素材处理

- **19 篇**使用精读文档内嵌的对照截图；**5 篇**的原封面帧是黑场或白场（83 秒 three.js、Blender 发布片、two-shot、Remotion 4K、49 分钟长片），由本站从作者原帖视频重新抽帧，页面上注明「本站按原视频重抽」。
- 非 16:9 的对照图（7 篇）在卡片与详情页都用 `contain` 完整展示，避免把上下两栏的对照裁成一半。
- 统一 900×506 或原始比例、JPEG q86，合计约 1.7 MB。

## 七、已知问题

- 第 12 篇「20 分钟 vs 1200 小时」的原帖在 2026-11-16 复核时返回 404（可能已删除或受限），对应的提示词镜像同样失效。页面保留该篇，按钮与提示条都写明「原帖当前不可访问」，数字来自精读文档的快照记录。
- 其余 23 篇原帖在 2026-11-16 复核时可正常打开。
- 24 篇的数字全部是作者自述或精读文档的记录，本站未复现任何一条链路。

## 八、继续添加

单篇新增需要：原始 Demo 链接、可核对的数字或结构描述、至少一张能对上的真实画面、来源与证据缺口。字段结构见 `src/content.config.ts` 的 `studies` 集合；`npm run check` 会强制校验链路拆解 ≥5 行、正文非空、Demo 链接合法、来源非空、媒体依据逐条登记。
