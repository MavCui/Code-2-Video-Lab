# 收录与分类说明

## 分类体系（2026-11-16 调整）

- **一级分类 = 行业**，一个条目单选：品牌与营销、艺术与实验、游戏与互动、数据与工具、教育与科普、媒体与出版、生活与消费、空间与建筑、研究与模型。
- **技术栈 = 独立标签维度**，可多选，来自页面或项目实际实现：Canvas 2D、SVG、CSS 3D、WebGL、Web Audio、DOM / CSS、原生 JS、React、Manim、Rust、FFmpeg 等。
- 原先的「教育讲解 / 品牌动效 / 产品演示 / 数据叙事 / 空间与运动 / 论文与文档」不再作为一级分类；12 个项目已迁移，技术栈仍保留在标签中。
- 展厅同时提供行业单选、技术栈单选与类型单选（项目 / 网页案例 / 创作作品 / 精读）；搜索覆盖名称、介绍、行业与技术栈。

## 二、案例（100 个）

- **来源**：`Claude Opus 5.5 · 100 HTML Files` 合集（合集页 / 仓库链接见 `docs/案例合集说明.md`）。
- **整套收录**：合集本身已经过作者策展与自动化检查（无外部请求、手机端无横向溢出、无控制台错误），100 个都有首屏截图与原始提示词，因此不再做二次筛选；分类与中文内容由本站重做。
- **本地化**：中文标题保留英文原名作副标题；一句话与案例说明由官方描述提炼，不逐字翻译长文；技术要点从描述与提示词中提取。
- **行业分布**：艺术与实验 37、游戏与互动 16、品牌与营销 14、教育与科普 8、媒体与出版 7、数据与工具 7、生活与消费 6、空间与建筑 5。
- **技术栈分布**：Canvas 2D 53、DOM / CSS 49、SVG 23、WebGL 5、Web Audio 4、CSS 3D 4、原生 JS 1（可多选，故总数大于 100）。
- **内容类型标记**：案例卡带「案例」角标，详情页标注「单文件网页」，与视频项目区分。

## 四、案例精读（24 篇）

来源是 `C2V_案例精读_24例_证据版`（从 1,671 条 X 索引与三份合集整理）。收录标准与前三个集合不同，是**「能算账」**：每篇至少要有一项可核对的数字或明确的结构描述（耗时、成本、token、调用次数、镜头数、额度占比），并且能回到作者原帖。

- 7 篇带完整成本对照表，其余带时长、token、调用次数、镜头数或额度占比。
- 不做跨案例排名与换算；作者没说明的口径统一写「未说明」。
- 反例与负样本同样收录：第 12 篇是「20 分钟 vs 1200 小时」这组不能相除的数字，第 23 篇是一条没有数字的进度抱怨。
- 行业覆盖艺术与实验 11、数据与工具 4、媒体与出版 3、教育与科普 3、品牌与营销 2、空间与建筑 1。

字段结构、素材处理与已知问题见 `docs/精读说明.md`。
