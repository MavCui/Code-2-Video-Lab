这条片子是什么

用工具本身介绍工具的 93 秒片。公开了成片、源码、捕获的命令输出、生成素材以及 bill.json，把 API 侧开销逐项记账，是少见的把「制作账目」当交付物一部分的案例。

亮点

  • 有可核对的成本文件 bill.json
  • 分列语音、转写、图片与视频生成，口径清楚
  • 同一团队的另一条片（Release 649）没有这套账单，两者不能混用
