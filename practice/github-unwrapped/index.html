这条片子是什么

个性化年度回顾应用。用户授权后读取 GitHub 数据，按个人贡献生成一支视频，再通过云函数并发渲染、缓存结果并对外提供下载。公开仓库包含应用源码、部署脚本与扩容思路。

亮点

  • 公开的是完整应用，不是一条片子：数据获取、渲染、缓存、并发都在里面
  • 适合讲批量生产架构，而不是单条创意
  • 个性化视频的瓶颈通常在队列与缓存，不在画面本身

可复用点与适用边界

可以迁移的

批量个性化视频要先解决并发与缓存，再解决画面

成立的条件

数据可以结构化，且模板能参数化

不能外推的

个人向短视频的架构不能直接用于长片或高画质交付

证据：已知与缺口

可以核对的

  • 应用源码与部署脚本公开
  • 数据来源明确（GitHub API）
  • 有并发与缓存的工程实现

尚未说明的

  • 未披露单条视频的渲染成本
  • 没有公开峰值并发下的实际耗时
  • 属于应用工程，不能当作 LLM 创作案例
