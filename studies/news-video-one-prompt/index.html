链路拆解

核心定位把资讯类口播视频的全流程压成一句提示词，输出中英两个版本。
适用场景资讯、吃瓜、热点解读类口播视频；需要快速出双语版本的场合。
必备输入话题 +（可选）素材链接或截图 + Gemini 3.8 Flash TTS 的 API Key；去敏选项（人名替换）。
标准流程给话题 → 自行检索素材 → 写稿 → 外部 TTS 配音 → 剪辑成片 → 输出中英两版。
AI职责检索、写稿、剪辑；配音交给外部 TTS。
关键指标目标：一条 5 分 51 秒的视频、中英两版。实际：两版成片均已发布；制作时长与费用未披露。

为什么值得看

这条链路的关键是“外挂 TTS”。作者明确写了配音用 Gemini 3.8 Flash TTS、并且自己提供了 API Key。这不是细节，而是架构选择：把声音交给专用模型，画面与剪辑留给主模型。评估这类方案时，要问的第一个问题是“哪些环节必须外挂”，而不是“能不能一句话搞定”。

去敏选项是个被低估的设计。提示词里留了“去掉人名”的开关，说明作者在把这类视频当产品做，而不是当作品做。可发布性——尤其是合规——往往是资讯类视频真正的瓶颈。

双语不是翻译，是重写。两版共享结构（开场钩子、事实铺陈、反转、收尾），但文案按语言重写。这也解释了为什么提示词里给的是“结构模板”而不是“逐字稿”。

可复用点与适用边界

可以迁移的

把流程拆成“结构模板 + 外挂专用模型”，比追求单模型端到端更现实。

成立的条件

需要自备 TTS 的 API Key；素材检索的准确性仍需人工复核。

不能外推的

没有时长与费用数据；事实核查环节完全依赖作者本人。
