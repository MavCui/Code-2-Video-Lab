案例说明

作者把旧短片交给 Opus 5.5，要求改成探索上海的像素游戏；原片场景被复用，角色与地图由模型调用图像工具制作，音乐音效在浏览器里实时合成，在线版本可以试玩。

制作细节

制作链旧短片场景复用 + 模型生成角色/地图 + 浏览器实时合成音乐音效
产出可在线试玩的像素城市游戏 + 约 179 秒录屏
耗时/成本未披露

看点

  • 旧短片场景直接复用为游戏地图
  • 音乐与音效在浏览器实时合成

证据与边界

这是多模型、既有素材与网页程序共同完成的创作链；可确认试玩结果，角色生成与「一次完成」仍以作者说明为准；所附视频是游戏录屏，不是独立生成的线性影片。
